# Icons

The full-color icons in this folder come from the **Papirus icon theme**
(https://github.com/PapirusDevelopmentTeam/papirus-icon-theme), © Papirus Development Team,
licensed under the GNU General Public License, version 3. See `COPYING-papirus`.

They're renamed for LaunchOS (for example `files.svg` is Papirus's `system-file-manager`).
App icons for Steam, Discord, Spotify and other apps aren't stored here: LaunchOS shows each
app's own icon, from the app itself or from Flathub's catalog.
